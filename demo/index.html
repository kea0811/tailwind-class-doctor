tailwind-class-doctor

Your Tailwind classes are fighting each other.

p-2 p-4 silently throws half your styles away. A CLI that scans your markup for duplicate, conflicting, and dead Tailwind classes — then rewrites them into one canonical, diff-friendly order with --fix.

Why a doctor?

Finds the real conflicts

Every utility is classified by the CSS property it writes, so text-lg fights text-sm but not text-red-500 — variants, shorthands, and !important included.

Fixes, not just complains

--fix dedupes, drops dead classes, and sorts every class string into one canonical order — in place, across JSX, HTML, Vue, Svelte, and @apply.

CI-friendly by design

Exit 1 on problems, --format json for tooling, and unknown classes like btn are never false-flagged.

Common uses

# Gate CI on "no conflicting Tailwind classes"
twdoctor src/ --no-order

# Normalize a whole codebase once, keep diffs quiet forever
twdoctor src/ --fix

# Check a suspicious class string from your clipboard
twdoctor -s "mt-2 flex p-2 p-4 flex" --fix

# Feed the report to another tool
twdoctor src/ --format json | jq '.summary'
$ pnpm add -g tailwind-class-doctor
